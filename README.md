Vice Cover Studio — an offline browser web app that turns your photos and a caption into GTA 6-style multi-panel cover art with a Vice City sunset/neon grade, exported as PNG in 1080x1080, 1080x1350 and 1920x1080. No uploads: photos never leave your machine. Original art and lettering; no Rockstar assets.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
